## Troubleshooting

- If the client does not start, restart the launcher and try again.
- Check that the selected Minecraft version matches the client configuration.
- Check that the required Java runtime is installed when the project requires one.
- Review recent changes to mods, resource packs, or configuration files.
- Temporarily remove recently added compatible mods to isolate a conflict.
- Read the error message and crash report before making additional changes.
- Update graphics drivers through the official vendor or operating-system update process.
- Ensure the system has sufficient free disk space and memory.
- Close unnecessary applications if the game is struggling to run.
- Record the exact steps that reproduce a crash before filing an issue.
